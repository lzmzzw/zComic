# 后台下载与 HyperOS 设置

Redmi K90 / HyperOS 3 用户实测切换应用后下载停止。小米官方说明，需要持续后台运行的应用应检查关闭省电模式、应用设为“无限制”、允许后台自启动和锁定后台应用。这提供了排查方向，公开资料没有给出 K90 / HyperOS 3 专属的停止阈值；仍需结合下载页“最近中断”和设备日志判断实际触发项。[小米官方后台权限说明](https://www.mi.com/uk/support/faq/details/KA-515548/)

## 在手机上设置

1. 打开 zComic → 下载 → 右上角设置，进入“后台下载设置”。也可从账号设置进入。
2. 点击“省电策略”，在 zComic 的应用省电设置选择“无限制”。若未能直达，在系统应用信息中查找省电策略或后台电量使用。
3. 点击“后台自启动”，允许 zComic。小米官方参考路径为设置 → 应用 → 权限 → 后台自启动，中文固件可能显示“应用设置 / 权限管理 / 自启动管理”；名称不同可在设置搜索“自启动”。[官方自启动说明](https://www.mi.com/global/support/faq/details/KA-507608/)
4. 若 Android 电池优化显示“未豁免”，点击“允许持续后台下载”，在系统弹窗中允许。它与 HyperOS 的“无限制”是不同层级，应用无法自动确认 HyperOS 私有开关。
5. 允许下载通知；下载期间关闭省电 / 超级省电，并在流量使用设置中允许后台联网。通知和网络限制状态会显示在应用内。
6. 在最近任务中长按 zComic 卡片选择锁图标，或在手机管家 → 设置 → 加速 → 锁定应用中选择 zComic。该设置主要防止“一键清理”，不等于解除省电限制。路径参考小米其他 Redmi 机型的公开说明，K90 菜单以实际显示为准。[官方后台锁定说明](https://www.mi.com/global/support/faq/details/KA-535435/)

设置完成后返回 zComic，继续已有下载，分别测试切换应用和锁屏数分钟，检查持续通知是否推进以及最终 EPUB 是否可读。若仍停止，记录“最近中断”、通知是否消失、重开后是否接续；未产生停止回调也可能是系统结束或冻结进程，不能仅凭没有错误推断下载还在运行。

## 应用支持与边界

v9 按厂商或品牌识别 Xiaomi、Redmi 和 POCO，为这些设备使用 dataSync 前台下载服务；这是针对用户实测的兼容方案，尚未在 K90 上验证效果。其他设备保持 UIDT 系统任务。两种执行方式共用持久队列与续传文件，升级保留进度；通知提供暂停全部。服务有超时保护的 CPU 唤醒锁，执行结束、暂停、取消或重试等待时释放。

自动恢复只针对排队或下载中的任务。队列清空、全部完成、取消或手动暂停后关闭恢复标记、停止下载组件，不注册周期保活或独立开机自启动。已暂停和失败任务由用户点击继续。系统重启服务时先检查恢复标记，过期标记对应的空队列也会立即结束，不登录网站。HyperOS 的“允许自启动”是系统权限，不表示应用会在无任务时常驻；系统可能短暂创建进程来分发已登记组件，应用不能控制系统每一次进程创建。

前台服务仍受系统及用户授权限制。Android 15+ 对 dataSync 后台服务设有运行配额，到达时限时应用停止服务、保存进度，返回应用后再继续；不从开机广播启动服务，也不能保证系统“强行停止”后自动恢复。[Android 前台服务限制](https://developer.android.com/develop/background-work/services/fgs/timeout)

系统设置跳转使用尽力可用的小米入口，失败时退回应用信息。应用只读取公开 Android 状态，不读取或改写 HyperOS 私有授权，也不把 Android 电池豁免显示为已完成所有后台设置。实际 K90 / HyperOS 3 设置入口及下载效果需要设备复测。
