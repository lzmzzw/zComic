# zComic 页面设计（评审稿）

视觉稿可查看 [六屏总览图](mockup-preview.png) 和 [可横向浏览的 HTML](mockup.html)。所有封面、书名、页数和下载状态均为演示内容，不代表站点数据。

## 视觉方向

以深色书店陈列为方向：近黑背景、低对比度分隔线、高饱和封面和少量珊瑚红操作色。封面承担作品识别，界面文字和状态保持清楚，不在封面上叠放大量按钮。手机竖屏书架与发现页每行两本；列表、队列和卷册页以紧凑行展示。

## 页面与交互

- 书架是启动首页。漫画按作品分组，默认最近阅读排序；作品卡片显示封面、名称、已下载卷数、最近阅读卷和进度。识别不出的导入文件进入“未分组”。顶部显示账号登录状态，登录可在设置中完成，不阻挡本地阅读。
- 作品书架页按卷号排列，用文字和颜色共同区分未读与已读。上次阅读的卷通过“继续阅读”直接打开。删除卷册先确认，成功后同时清除该卷阅读位置。
- 发现页顶部搜索，下方默认网站“最近更新”的双列封面网格。搜索结果沿用网格；空结果和网络错误提供明确状态及重试。
- 漫画详情页展示封面、名称、简要信息和卷册列表。可选卷册使用复选框；已下载或已排队卷册显示状态且不可重复加入。选中后底部固定操作栏显示数量与“加入下载”。
- 下载页是一个列表，按任务时间排序，每行显示作品、卷号、大小或进度及状态。暂停、继续、重试、取消靠近对应任务；顶部菜单提供“清除已完成记录”，只清列表，不删除 EPUB 或书架条目。
- 阅读器默认全屏、隐藏工具栏，中央轻点显示或隐藏。显示工具栏时有“第 x 页 / 总页数”和可拖动进度条；设置可配置边缘点击与滑动翻页。分页支持左右方向，另有上下连续模式。背景可切换深色、浅色；支持适应宽度、适应整页与横竖屏。横屏仍为单页，不做双页。

## 状态与尺寸起点

触控目标不小于 44dp，底部导航图标配文字。常规页面外边距约 16dp，两列封面间距约 12dp；封面保持统一纵横比。已读、未读、失败、排队和登录状态除颜色外均有文字或图标。适配系统字体放大与屏幕安全区；最终尺寸需在两台设备上核验。

视觉稿为静态设计参考，不代表登录、网站访问、下载或 EPUB 阅读已经实现。
