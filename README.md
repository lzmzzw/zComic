# zComic

个人使用的 Android 漫画应用，面向 Android 15 及以上设备。应用访问 [Kmoe](https://kxo.moe/)，检索漫画，下载单卷 EPUB 到 `Documents/zComic`，并在应用内离线阅读。两台个人设备各自保存账号会话、下载记录和阅读位置，不提供同步或分发。

当前处于设计阶段，尚未实现应用或验证登录后的站点接口。功能与验证门槛见 [设计方案](docs/design.md)；页面方案与视觉稿见 [页面设计](docs/pages.md)。

账号在应用内首次输入；后续尝试自动登录。账号密码不得写入源码、构建配置或 APK。登录态和必要凭据只保存在设备上，自动登录失败时提示重新输入。
